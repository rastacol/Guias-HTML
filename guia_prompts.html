Uso Interno

Guía estandarizada para la interacción y parametrización de prompts.

Eres un [profesión] con [X años] de experiencia en [especialidad]
Actúa como un [rol] que es [característica]
Eres un experto en [campo] ayudando a un [tipo de audiencia]
Contexto — Qué incluir
Detalles del proyecto
Stack tecnológico, arquitectura, restricciones
Estado actual
Qué has intentado, qué funciona, qué no
Objetivos
Qué estás tratando de lograr finalmente
Restricciones
Límites de tiempo, requisitos técnicos, guías de estilo
Verbos de acción que funcionan bien

Creación Escribe, Crea, Genera, Compone, Diseña

Explicación Explica, Describe, Aclara, Define, Ilustra

Tipos de restricciones

Longitud

Mantén tu respuesta bajo 200 palabras
Proporciona exactamente 5 sugerencias
Escribe 3-4 párrafos

Contenido

No incluyas ejemplos de código
Enfócate solo en los aspectos técnicos
Evita lenguaje de marketing

Estilo

Usa un tono formal y académico
Escribe como si hablaras con un niño de 10 años
Sé directo y evita lenguaje evasivo

Alcance

Solo considera opciones disponibles en Python 3.10+
Limita las sugerencias a herramientas gratuitas
Enfócate en soluciones que no requieran dependencias adicionales
Formatos de Salida

Listas

Devuelve como una lista con viñetas
Proporciona una lista numerada con una breve explicación para cada uno. Cada elemento de la lista debe estar en negrita, seguido de un guión y explicación

Datos estructurados

Devuelve como JSON con claves: título, descripción, prioridad
Formatea como una tabla markdown con columnas: Característica, Pros, Contras
Formatea como una tabla markdown con columnas: | [columna 1] | [columna 2] | [columna 3] | [columna 4] |

Estructuras específicas

Estructura tu respuesta como: ## Resumen / ## Puntos Clave / ## Recomendaciones

Encabezados y secciones

Estructura tu respuesta con estas secciones:

## Resumen Ejecutivo
## Fortalezas
## Debilidades
## Recomendaciones
## Evaluación de Riesgos
Directivas en mayúsculas comunes

NUNCA

Prohibición absoluta: "NUNCA incluyas opiniones personales"

SIEMPRE

Requisito obligatorio: "SIEMPRE cita fuentes"

IMPORTANTE

Instrucción crítica: "IMPORTANTE: Mantén las respuestas bajo 100 palabras"

NO

Prohibición fuerte: "NO inventes estadísticas"

DEBE

Acción requerida: "La salida DEBE ser JSON válido"

SOLO

Restricción: "Devuelve SOLO el código, sin explicaciones"
Prompts CoT básicos
Pensemos paso a paso.
Piensa esto cuidadosamente.
Trabaja este problema metódicamente.
Muestra tu razonamiento en cada paso.
Explica tu proceso de pensamiento.
CoT para toma de decisiones
[ Decisión a tomar? ]
[Contexto]

Piensa esto sistemáticamente:

1. Lista el estado actual
2. Identifica factores a considerar (factor 1, factor 2, factor 3, factor n)
3. Sopesa cada factor como a favor/en contra
4. Da una recomendación con razonamiento
GAN para toma de decisiones
Use a GAN-style thinking framework — give me specific critiques and concrete suggestions.
